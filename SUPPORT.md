# Support

Open Cluster Foundation is a community project and does not include a support
SLA. Maintainers and contributors help on a best-effort basis.

Use [GitHub Discussions](https://github.com/pyahu/open-cluster-foundation/discussions)
for installation questions, design proposals and provider implementation
coordination. Search existing discussions and documentation before opening a
new topic.

Use [GitHub Issues](https://github.com/pyahu/open-cluster-foundation/issues) for
reproducible defects and scoped feature requests. Choose the matching issue form
and include the OCF release, cloud provider, Kubernetes version, selected
environment, failed command and sanitized error output. Never include
credentials, private keys, tokens, real customer identifiers or unrestricted
kubeconfigs.

Report vulnerabilities only through the private process in
[`SECURITY.md`](SECURITY.md). Do not disclose them in Issues or Discussions.

Only the latest release receives fixes. Before requesting help, reproduce the
problem on that release when it is safe to do so and review
[`docs/lifecycle.md`](docs/lifecycle.md) for evidence collection, rollback and
recovery guidance.
